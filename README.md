# Armazém São Caetano — site institucional

Site responsivo de uma página para apresentar a experiência do Armazém São Caetano, gastronomia, bar, eventos, contatos e localização.

## Como visualizar

Abra o arquivo `index.html` em um navegador. Para uma experiência de desenvolvimento mais próxima da hospedagem, rode um servidor local simples na pasta do projeto, por exemplo `python -m http.server 8000`, e acesse `http://localhost:8000`.

## Arquivos

- `index.html`: conteúdo e estrutura das seções.
- `styles.css`: identidade visual, layout responsivo e estilos para celular.
- `script.js`: menu mobile e ano automático no rodapé.
- `assets/cardapio-inverno-2026.pdf`: cardápio fornecido como referência.
- `assets/logo-armazem.jpg`: recorte do logo visível na imagem de referência fornecida.

## Antes de publicar

- Confirme com o restaurante se os preços do PDF e o cardápio de inverno continuam válidos.
- Confirme horários de funcionamento e política de reservas antes de adicionar esses dados ao site.
- As fotografias de destaque usam imagens remotas do Unsplash e precisam de internet para carregar.
- O mapa abre uma busca do endereço no Google Maps; não é um mapa incorporado.


## Responsividade
O layout inclui ajustes para desktop, tablets e celulares, com menu recolhível, categorias do cardápio com rolagem horizontal em telas estreitas, cards fluidos e controles com área de toque adequada. Para testar, redimensione a janela do navegador ou use as ferramentas de dispositivo do Chrome/Edge.
